# 06 - Domain Terminology & Ubiquitous Language

To prevent LLM hallucination and ensure precise communication, the following terms hold strict definitions within this repository:

- **Spec (`*.spec.md`):** The human-readable functional requirement document. The highest level of truth.
- **DevSpec (`*.devspec.md`):** The technical translation of a Spec into a Behavioral Matrix (input, state, expected output). Directly drives TDD.
- **AI Slop:** Unnecessary filler vocabulary (e.g., "delve", "robust"), emojis, or sycophantic phrasing generated by LLMs. Strictly banned.
- **AHA (Avoid Hasty Abstractions):** The principle of waiting for three identical use-cases before abstracting code, prioritizing readability over premature DRY (Don't Repeat Yourself).
- **Static-First:** The architectural mandate that all pages resolve to static HTML at build time, eliminating runtime server attack surfaces.
