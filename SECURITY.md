# Security policy

## Scope

This policy covers the website at https://www.pa-tech.dev and the code in this repository. The hosting (statichost.eu), GitHub and the sites the pages link to are out of scope; report issues there to their owners.

## Reporting a vulnerability

Report it privately through GitHub's form: [Report a vulnerability](https://github.com/Alexits93/ai-architecture-portfolio/security/advisories/new). Please do not open a public issue or pull request for it.

Include what you found, where (URL or file), how to reproduce it, and what an attacker could do with it.

## Disclosure

This is a personal site maintained by one person, with no bug bounty. I read every report, confirm or decline it in the advisory, and fix confirmed issues. Please keep the details private until the fix is published; we agree on the disclosure in the advisory.
