# Docs

- Plans and specs live in GitHub issues, not in the repo. The repo keeps `docs/ARCHITECTURE.md` (runtime behavior that code alone doesn't show) and `docs/adrs/` (why a decision was made).
- Diagrams are mermaid, never binary images.
- Update a doc by overwriting it with the current rule, not by appending history.
